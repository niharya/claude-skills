# Notes — Northwind Cloud (default example)

This is a reference run shipped with the skill. The candidate, company, and details are fictional. Use it to understand the shape of an application folder; delete it once you've run your own first application.

## Files

- `jd.txt` — the cleaned JD.
- `positioning.md` — per-application positioning doc.
- `data.json` — resume data structure that feeds the build script.
- `application.md` — one H1 section per form field, including the cover letter.
- `resume.html` — generated by `python3 scripts/build.py default --pdf` (or without `--pdf` for HTML only).

## What this example demonstrates

- A senior IC application without a thesis-style headline (positioning.md sets `headline_pattern: chronology`, so no headline appears at the top of the resume).
- A `data.json` shape with three roles, an education entry, and no `selected_work` block.
- An `application.md` with three field sections — cover letter, "biggest project recently", "why this company" — plus a LinkedIn field.

## Try it

From the skill root:

```
python3 scripts/build.py default
```

You should see a one-line summary like:

```
Built default · 1 page · parse: clean · voice: clean · NDA: clean · JD signal: 9/12 present
```

And a freshly rendered `resume.html` in this folder. Add `--pdf` to also render `resume.pdf` (requires WeasyPrint).
