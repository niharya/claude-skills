# What's the biggest project you've shipped recently?

The v2 docs site at Helio. Our time-to-first-deploy was 14 minutes, measured by event from "land on docs" to "first successful deploy". We rebuilt the docs as a guided onboarding rather than a reference site. The first three pages walk you through deploy, environment variable, custom domain. Reference docs sit behind it for when you need them.

Brought it down to 5 minutes. The numbers are the headline. The more useful thing for us was that the docs became the surface PMs and DevRel actually used in customer calls. They became a tool, not a deliverable.
